## 2. 采集方式

采集入口是 5070 Ti 上的 `~/yuhang_workspace/wall_oss_rlt/tools/wall_collect.py`，它用固定参数调用采集工程的 `collect.py`。生效的参数和每次启动时的代码版本记在数据根目录的 `wall_collection.json` 里，契约的 provenance 带着这个文件的 sha256。

| 项 | 设置 |
|---|---|
| 映射 | 相对映射：按下开始时记住主臂和从臂的位姿，之后从臂跟主臂的**变化量**走。平移 ×0.8，转动 ×0.2，主臂腕部自转单独 ×0.6 直接转夹爪自身轴 |
| 逆解 | 本机 weighted 逆解，受控点是**指尖**（法兰沿自身 z 轴外 130 mm），位置权重 50、姿态权重 0.5；50 Hz 给臂发关节目标 |
| 起始姿势 | 每条都从同一姿势开始（夹爪斜向下）：`q0 = [-0.7415, -0.0008, 0.0919, 1.8059, -1.3811, 0.3432, -0.4173]` 弧度，即 `[-42.5, -0.0, 5.3, 103.5, -79.1, 19.7, -23.9]` 度，夹爪张开。150 条第一帧的标准差 < 0.001° |
| 工作空间盒 | 指尖被限制在 x 0.00~0.66、y −0.60~0.43、z 0.08~0.65 m（基座系）。这个盒子**没有**记在 `wall_collection.json` 里，只能从代码版本查到 |
| 夹爪 | 空格夹紧、O 松开，只发 0 / 1。张开时的目标位置封顶 180（开度 0.857）；夹持力 80、速度 128 |
| 代码版本 | 150 条全部在 DexGraspVLA- 提交 `7cedebf`（分支 `ar5-cartesian-start-posture`）下录制 |
| 采集日期 | 2026-11-03 |

按下夹紧或松开时，臂先停住，等夹爪夹牢或张开到位再接着跟。这段停顿也录进了数据，见第 7 节。

## 4. 约定

| 项 | 约定 |
|---|---|
| 坐标系 | AR5 基座坐标系，z 朝上 |
| 位姿参考点 | `ee_pose`、`action` 用的是**法兰**（臂末端安装面），不是指尖。采集时逆解控制的是指尖（法兰沿自身 z 轴 130 mm），两者不要混 |
| 姿态表示 | 轴角（旋转向量）：方向是转轴，模是转角。由控制器的欧拉角换算，`R = Rz(rz)·Ry(ry)·Rx(rx)` |
| 关节顺序 | j1 ~ j7，对应控制器的轴 1 ~ 7 |
| 夹爪开度 | 0 = 全合（位置 0），1 = 位置 210。开度 = 位置 ÷ 210。张开时停在 0.857（位置 180） |
| 时间 | 秒 |

## 5. npz 字段

### 5.1 `state`（T×8，float32）：实测状态

| 维 | 含义 | 单位 |
|---|---|---|
| 0–6 | j1 ~ j7 关节角，实测 | 弧度 |
| 7 | 夹爪开度，实测 | 0 ~ 1 |

* 7 个关节都在动，没有常数维。
* 夹住物体时开度停在物体宽度上：bolt 0.17~0.22（中位 0.20），orange_block 0.29~0.39（中位 0.35），black_bushing 0.37~0.41（中位 0.40）。

AR5 软限位（弧度）：

| | j1 | j2 | j3 | j4 | j5 | j6 | j7 |
|---|---|---|---|---|---|---|---|
| 下限 | −3.1067 | −2.0944 | −3.1067 | −1.0472 | −3.1067 | −0.8727 | −0.8727 |
| 上限 | 3.1067 | 2.0944 | 3.1067 | 2.5307 | 3.1067 | 0.8727 | 0.8727 |

### 5.2 `action`（T×7，float32）：最容易用错

| 维 | 含义 | 单位 / 取值 |
|---|---|---|
| 0–2 | 法兰平移增量 `p[t] − p[t−1]` | 米，基座系 |
| 3–5 | 法兰旋转增量 `R[t] · R[t−1]ᵀ` 的轴角（基座系下左乘） | 弧度 |
| 6 | 夹爪**指令** | 1 = 张开，0 = 夹紧，没有中间值 |

> **用之前必须知道的四点**
>
> 1. **这是「从上一帧走到这一帧」，不是「从这一帧往下一帧走」。** `action[0]` 的前 6 维恒为 0。
> 2. **前 6 维是用实测法兰位姿算的，不是下发给臂的指令。** 下发的关节目标没有存。
> 3. **参考点是法兰，不是指尖。**
> 4. **第 6 维是按键指令，不是开度。** 实测开度在 `state[:, 7]`。

和 `ee_pose` 的关系：`action[t, :6] == pose_delta(ee_pose[t-1], ee_pose[t])`。150 条实测，平移误差 ≤ 4.3e-8 m，旋转误差 ≤ 2.6e-7 rad（比较的是旋转本身，不是轴角分量）。scipy 写法：

```python
from scipy.spatial.transform import Rotation as R
# 增量：上一帧 a → 这一帧 b
d_pos = b[:3] - a[:3]
d_rot = (R.from_rotvec(b[3:]) * R.from_rotvec(a[3:]).inv()).as_rotvec()
# 叠回去：a + 增量 → b
b_pos = a[:3] + d_pos
b_rot = (R.from_rotvec(d_rot) * R.from_rotvec(a[3:])).as_rotvec()
```

### 5.3 `ee_pose`（T×6，float32）：法兰绝对位姿

`[x, y, z, 轴角三个分量]`，法兰在基座系下的位姿，单位米和弧度。

* **轴角在转角接近 π 时会翻到另一支。** 起始姿势的转角就接近 π；orange_block、black_bushing 里轴角的模到了 3.142，相邻两帧的分量最大跳了 5.9（同一个旋转换了一种写法）。**不要直接对轴角分量做差、插值或归一化。** 第 6 节的训练目标先转成旋转矩阵再取 6D，不受影响。
* 各任务法兰位置范围（米）：

| 任务 | x | y | z |
|---|---|---|---|
| bolt | 0.153 ~ 0.331 | −0.345 ~ −0.127 | 0.255 ~ 0.487 |
| orange_block | 0.105 ~ 0.432 | −0.436 ~ −0.065 | 0.212 ~ 0.509 |
| black_bushing | 0.054 ~ 0.422 | −0.434 ~ 0.029 | 0.214 ~ 0.484 |

### 5.4 图像

| | `cam_high` | `cam_front` |
|---|---|---|
| 相机 | Gemini 335 | Gemini 305 |
| 安装位置 | 台架上，俯视工作台 | 夹爪上方，朝夹爪方向看 |

### 5.5 时间与对齐

* **基准是腕部相机每一帧的拍摄时刻**：`timestamp == t_cam_front`（150 条逐帧相等）。
* 关节角、夹爪开度按这一刻插值，法兰姿态做球面插值；夹爪指令取这一刻正在生效的值，不插值。
* 俯视图取拍摄时刻最近的一张，离基准中位 7~9 ms，最大 32 ms。
* 采集时按回车暂停的那段已经从时间轴上抹掉，暂停前后的帧直接接上。

## 6. 训练目标：`ar5_ee_rel6d_next_v1`

按官方 Wall-OSS-0.5 的 LeRobot 做法（wall-x `x2robot2lerobot.py`：state 取第 i 帧、action 取第 i+1 帧，都是跟随臂的实测位姿）。实现在本项目 `wall_rlt/data/ar5.py`、`wall_rlt/data/prepare_ar5.py`。

| | 内容（10 维） |
|---|---|
| 观测 state（第 t 帧） | 法兰位置 3（米）＋ 6D 姿态 6 ＋ **实测**开度 1 |
| 动作（第 t 帧起 32 步） | 第 t+1+k 帧（k = 0..31）相对第 t 帧：位置差 3 ＋ 相对姿态的 6D 6 ＋ 第 t+1+k 帧的夹爪**指令** 1 |

* 6D 姿态 = 旋转矩阵的前两行，按行展开；相对姿态 `R_rel = R[t+1+k] · R[t]ᵀ`，和 wall-x `LerobotDataset._to_relative_action` 一致。
* 夹爪这一维是二值指令（0 / 1），不做相对，用户 11-02 决定。
* 每条最后一帧没有下一帧，不作为观测；窗口超出条尾的步标记为无效，不参与损失。
* 放在 Wall-OSS-0.5 的 26 维布局里右臂的槽位 10~19（位置 10~12、6D 13~18、夹爪 19）。加载官方权重**不重置**动作投影，只换成本数据 train 划分的归一化（q01 / q99）。

## 7. 数据里的行为特点（影响建模）

**三个任务共同的：**

| 现象 | 具体情况 |
|---|---|
| 起始姿势完全相同 | 每条第一帧都是第 2 节的 `q0`，夹爪张开 |
| 夹紧时臂停住 | 按下夹紧后臂冻住，等夹牢再接着动：orange_block 1.0~2.1 s，black_bushing 1.0~1.3 s，bolt 1.2~2.4 s。这段静止是演示的一部分 |
| 静止帧多 | 每帧平移 < 0.2 mm 且转动 < 0.05° 的帧：orange_block 40%，black_bushing 33%，bolt 52% |
| 有的条贴着关节限位 | 逆解在软限位内留 0.05 rad（2.86°）余量。离软限位不到 5° 的：orange_block 24、27（j7）、32~35（j6）；black_bushing 16、17（j4）、23、26、29、31、38、45、47（j6）；bolt 没有。大多数就停在 2.86° 那条线上，说明那一刻逆解被限位卡住、没完全跟上主臂。j6、j7 的软限位只有 ±50° |

**两个抓取任务（orange_block、black_bushing）：**

* 夹爪只动一次（张开 → 夹紧），夹住抬起就结束，**没有放下、没有再张开**。夹紧发生在全条的 43%~87% 处。
* 物体每条摆的位置都不同。指尖抓取点：orange_block x 155~474 mm、y −503~−162 mm；black_bushing x 82~479 mm、y −497~−85 mm。
* orange_block 从 31 号起（30 号已剔除，29 号和 31 号之间停了约 12 分钟）俯视画面的背景变了：右上角的白托盘被拿走，泡沫板挪了约 1 cm。相机本身没动。

**bolt：**

* 流程是抓螺栓 → 移到套筒上方 → 对准插入 → 松手。夹爪指令每条都是张开 → 夹紧 → 张开。夹紧发生在全条的 12%~39% 处。
* **摆放固定**：螺栓（粉红色头）竖在板子左侧的蓝色底座里，黑色套筒固定在板子右侧。各条松手时指尖位置的标准差约 8 mm，抓取点范围约 3 cm。
* 插入时夹爪斜着，和竖直方向约成 50°。
* **插入阶段相机看得不清**：俯视相机只能看到螺栓头旁边的一段套筒边（约 20 像素）；腕部相机只看到螺栓头，套筒在它正下方被挡住。对准主要靠臂的位置，套筒挪动几厘米就超出了数据覆盖的范围。
* 指尖进入松手点 3 cm 以内到松手，用时 3.1~19.5 s（中位 5.6 s）。0~13 号还不熟练，要 8~20 s、停 3~8 次；后面一般 3~5 s、停 1 次。
* 松手后臂不往上撤，0.9~6.5 s（中位 1.3 s）后存盘结束。50 号俯视画面里板子右侧外多放了一块橙色方块。松手那一下夹爪弹开，开度短暂到过 0.915。

| 项 | 要求 |
|---|---|
| 起始姿势 | 先回第 2 节的 `q0`。5070 Ti 上：`cd ~/yuhang_workspace/算法/DexGraspVLA-/SO101 && PYTHONPATH= ~/miniforge3/envs/dexgraspvla/bin/python -m atom_robot.ar5.unseize --recover --home`（`home_collect` 也回这里） |

| 模型输出怎么用 | 32 步都是**相对出动作那一刻的法兰位姿**：目标位置 = `p_t + Δp`，目标姿态 = `R_rel · R_t`（6D 先按 Gram-Schmidt 还原成旋转矩阵）。参考点是法兰 |
| 频率 | 数据 30 Hz；采集时 50 Hz 给臂发关节目标 |
| 夹爪 | 只发 **0 或 1**，夹持力 80、速度 128，张开目标封顶 180。**不要把实测开度当指令发**：夹爪走到那个位置会判「已到达」并卸力，物体只是被松松含着 |

| 场景 | 两台相机不能挪；bolt 的螺栓底座和套筒要放回采集时的位置 |

import json
